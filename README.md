# 计算机-学习网站

专升本备考学习网站（纯前端，无服务器，GitHub Pages 部署）。

## 功能模块
- 🐍 **Python**：230 题练习（拖拽排序）+ 77 条知识点地图
- ☕ **Java**：251 题练习（拖拽排序）+ 速查手册 + 85 条知识点地图
- ⚙️ **C 练习**：230 题 + 📖 **C 语法基础**（6 章零基础小课：变量/数组/指针/结构体/递归/内存）
- 🆎 **英语**：背单词（每日 20 词 + 打卡，3405 词）+ 写作范文 50 篇（中英对照）
- 📚 **数据结构**：9 章动画/模拟/测验/定时复习（C 语言代码示例）+ 每章 3 道编程练习（读代码/补全/完整编程，带在线自测对拍）
- 🏆 **蓝桥杯**：15 道省赛风格真题
- 🛠 小工具：番茄钟（自定义时长）、待办清单
- 🌙 暗色模式、进度本地保存（localStorage）

## 使用
直接用浏览器打开 `index.html` 即可本地使用；部署到 GitHub Pages 后电脑/手机均可访问，进度自动保存在浏览器本地。

## 技术
纯 HTML/CSS/JavaScript，无任何外部依赖，数据文件为独立 JS。
